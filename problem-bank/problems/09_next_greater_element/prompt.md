# Next Greater Element II (circular) simplified — Next Greater Element (non-circular)

Given an array `nums`, return an array `answer` where `answer[i]` is the next greater element of `nums[i]`.
The next greater element is the first greater number to the **right** of `i`. If none, use `-1`.

## API

```python
def next_greater_elements(nums: list[int]) -> list[int]
```
