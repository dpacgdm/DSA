# SECTION A — ANSWERS

### A1
Graphs allow cycles, multiple parents, and disconnected pieces (and directed one-way edges). Without `visited`, traversal can loop forever on a cycle.

### A2
**List** for sparse graphs / BFS-DFS — space O(V+E). **Matrix** for dense graphs or O(1) edge checks — space O(V²).

### A3
Each vertex processed ≤ once; each edge examined ≤ constant times via neighbor lists → O(V+E). Scanning all edges per vertex → O(V·E).

### A4
BFS explores by increasing distance rings; first discovery is minimal edge count. Different weights → BFS wrong; need Dijkstra (Module 8).

### A5
`len(q)` is evaluated once before the for-loop, freezing the current layer size while new nodes append for the next layer. A bare `while q` without a frozen count mixes levels.

### A6
On **exit** (postorder), after all descendants finish. For edge u→v in a DAG, v finishes before u, so reversing finish order yields topo.

### A7
The edge back to your parent is not a cycle. Without `parent`, every undirected edge looks like a back edge → false cycle.

### A8
WHITE unvisited; GRAY on recursion stack; BLACK finished. Neighbor **GRAY** ⇒ back edge ⇒ directed cycle.

### A9
A **cycle** exists (not a DAG). 3-color DFS also detects it (GRAY back edge).

### A10
Presence of an **odd cycle**. Conflict when a neighbor is already colored the **same** as the current node.

### A11
**DAG**. Undirected "topo" is not well-defined for prerequisites — you need directed constraints.

### A12
Nodes/edges are generated by a neighbor function, not stored up front. Examples: Word Ladder, Open the Lock, grid shortest path.

### A13
Otherwise the same node can be enqueued many times from different parents before it is processed → queue blowup / worse complexity. Mark on enqueue keeps "first touch wins."

### A14
Add **`b → a`** (b before a). Kahn peels indegree-0 sources first.

### A15
PREVIEW: min-heap of `(distance, node)`; BFS assumes unit weights so it can mis-order when edge costs differ.

```python
from collections import deque

def bfs_dist(graph, start):
    q = deque([start])
    dist = {start: 0}
    while q:
        u = q.popleft()
        for v in graph[u]:
            if v not in dist:
                dist[v] = dist[u] + 1
                q.append(v)
    return dist
```

### C1
indeg `[0,1,1,2]`; queue `[0]` → pop 0 → `[1,2]` → … → order e.g. `[0,1,2,3]` or `[0,2,1,3]`.

### C2

```python
from collections import deque

def topo_kahn(n, edges):
    graph = [[] for _ in range(n)]
    indeg = [0] * n
    for u, v in edges:
        graph[u].append(v)
        indeg[v] += 1
    q = deque([i for i in range(n) if indeg[i] == 0])
    order = []
    while q:
        u = q.popleft()
        order.append(u)
        for v in graph[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    return order if len(order) == n else None
```

### C3

# SECTION D — ANSWERS

### D1

**Pattern:** Unweighted shortest path on implicit word graph → **BFS**.

```python
from collections import deque

def ladder_length(begin_word, end_word, word_list):
    word_set = set(word_list)
    if end_word not in word_set:
        return 0
    q = deque([(begin_word, 1)])
    visited = {begin_word}
    while q:
        word, length = q.popleft()
        if word == end_word:
            return length
        for i in range(len(word)):
            for ord_c in range(26):
                c = chr(ord("a") + ord_c)
                if c == word[i]:
                    continue
                nxt = word[:i] + c + word[i+1:]
                if nxt in word_set and nxt not in visited:
                    visited.add(nxt)
                    q.append((nxt, length + 1))
    return 0
```

**Trace:**
```
(hit,1) → hot
(hot,2) → dot, lot
(dot,3) → dog
(lot,3) → log
(dog,4) → cog
(cog,5) → return 5
```

**Neighbors:** 26×L mutations + set lookup — not all-pairs.

> **Time: O(n · 26 · L²)** (string ops), **Space: O(n · L)**

### D2
Return **0**; check `end_word not in word_set` at start.  
DFS finds *a* path, not necessarily the **shortest**; ladder length would be wrong.

### D3

```python
from collections import deque, defaultdict

def alien_order(words):
    graph = defaultdict(set)
    indeg = {}
    for w in words:
        for ch in w:
            if ch not in indeg:
                indeg[ch] = 0
                graph[ch] = set()
    for i in range(len(words) - 1):
        w1, w2 = words[i], words[i + 1]
        min_len = min(len(w1), len(w2))
        if len(w1) > len(w2) and w1[:min_len] == w2[:min_len]:
            return ""
        for j in range(min_len):
            if w1[j] != w2[j]:
                if w2[j] not in graph[w1[j]]:
                    graph[w1[j]].add(w2[j])
                    indeg[w2[j]] += 1
                break
    q = deque([c for c in indeg if indeg[c] == 0])
    order = []
    while q:
        c = q.popleft()
        order.append(c)
        for nxt in graph[c]:
            indeg[nxt] -= 1
            if indeg[nxt] == 0:
                q.append(nxt)
    if len(order) != len(indeg):
        return ""
    return "".join(order)
```

**Edges:** t→f, w→e, r→t, e→r.  
**Kahn:** w → e → r → t → f → `"wertf"`.

> **Time: O(C)**, **Space: O(V+E)** (V≤26)

(b) `""` — longer word before its own prefix violates dictionary order.

```python
def can_visit_all_rooms(rooms):
    seen = set()
    stack = [0]
    while stack:
        u = stack.pop()
        if u in seen:
            continue
        seen.add(u)
        for k in rooms[u]:
            stack.append(k)
    return len(seen) == len(rooms)
```

```python
from collections import deque

def is_bipartite(graph):
    n = len(graph)
    color = [-1] * n
    for s in range(n):
        if color[s] != -1:
            continue
        color[s] = 0
        q = deque([s])
        while q:
            u = q.popleft()
            for v in graph[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    q.append(v)
                elif color[v] == color[u]:
                    return False
    return True
```

### H7

```python
def has_cycle(n, edges):
    g = [[] for _ in range(n)]
    for u, v in edges:
        g[u].append(v)
        g[v].append(u)
    vis = [False] * n

    def dfs(u, parent):
        vis[u] = True
        for v in g[u]:
            if not vis[v]:
                if dfs(v, u):
                    return True
            elif v != parent:
                return True
        return False

    for i in range(n):
        if not vis[i] and dfs(i, -1):
            return True
    return False
```

### H8
